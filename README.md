## Overview

Orris is a smart, premiumm notes application designed for users who want more than simple text storage. It helps capture thoughts quickly, organize them sophisticatedly, and makes access to everything securely from anywhere. Built with Next.js and React, blends speed, usability, and reliability in one intuitive interface.


## Features

### Folder Organization
Group related notes into folders to maintain a clear and logical structure. Create, rename, or delete folders instantly without disrupting your notes.

### Reordering Notes
Easily rearrange notes and folders using drag-and-drop interactions to customize the layout according to your workflow.

### Pinning Notes
Keep your most important or frequently accessed notes at the top of your list with a simple pin feature for quick reference.

### Rich Text Editor
Write and style notes using a versatile editor that supports headings, formatting, and code blocks. Create content that looks clean and is easy to revisit.

### Image Uploads
Attach images directly to your notes through secure cloud integration. It supports uploads using Supabase Storage, allowing for fast, reliable, and scalable media handling.

### Search and Filter
Find notes quickly with advanced search and filter capabilities. Instantly locate content by title, keyword, or folder.

### Cloud-Backed Data
All notes and uploads are safely stored in the cloud using a managed database and storage solution. Your data stays synced, accessible, and protected.

### Authentication
It includes secure login and session management to keep user data private and isolated. Only authenticated users can create or modify notes.

### Responsive Design
Optimized for all screen sizes. Use Orris with ease on desktops, tablets, and mobile devices.
